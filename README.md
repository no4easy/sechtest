# Учебная база — Telegram Mini App

Публичное мини-приложение для поиска ответов в PDF и прохождения тестов. Сервер использует Python 3.10+, SQLite и системную утилиту `pdftotext` (пакет poppler-utils). Сторонние Python-пакеты не требуются.

В проект включены четыре самостоятельных раздела: **Холиномиметики (186 заданий)**, **Холиноблокаторы (223)**, **Адреномиметики (172)** и **Средства для органов пищеварения (199)**. Всего 780 заданий. Данные находятся в четырёх файлах `seed_*.json` и автоматически добавляются в SQLite при запуске. Повторные запуски не создают дубли. Два вопроса (№ 224 в холиноблокаторах и № 70 в адреномиметиках) пропущены, поскольку в исходных PDF нет ключа ответа. Для заданий на последовательность и соответствие приложение показывает эталон и предлагает оценить свой ответ самостоятельно. Исходные PDF в репозиторий добавлять не требуется.

На первом экране выберите раздел. Поиск и прохождение теста работают только с вопросами выбранного раздела; каждый проход содержит до 20 случайных заданий из него.

После теста нажмите «Посмотреть ошибки этого прохода» или «Ошибки раздела». Список содержит ваш ответ и правильный ответ; кнопка «Перерешать» запускает только выбранные ошибочные вопросы. При правильном ответе во время повторения вопрос удаляется из ошибок. Списки ошибок хранятся отдельно для каждого раздела в памяти браузера на текущем устройстве; очистка данных Telegram или переход на другое устройство удалит или не перенесёт их.

## С телефона: GitHub → Railway → Telegram

1. Создайте [частный репозиторий GitHub](https://github.com/new) или откройте существующий репозиторий приложения. Через **Add file → Upload files** загрузите содержимое папки `telegram-study-app` из архива **в корень репозитория**, включая три файла `seed_*.json`. Railway должен видеть `Dockerfile` в корне, поэтому загружать один ZIP-файл нельзя. Если кнопка загрузки скрыта, включите в браузере телефона режим «Версия для ПК».
2. На [Railway](https://railway.com/) создайте проект **Deploy from GitHub repo**, подключите репозиторий и дождитесь сборки Dockerfile. Приложение использует выданный платформой `PORT`.
3. В разделе **Variables** задайте `ADMIN_TOKEN` (длинный случайный код), если хотите загружать новые материалы. Для ответов ИИ добавьте `OPENAI_API_KEY`; модель при необходимости задаётся через `OPENAI_MODEL`. Секреты храните в Railway, не в GitHub. Токен Telegram-бота этому приложению не нужен.
4. Подключите к сервису **Volume** с путём монтирования `/data` и установите `DATABASE_PATH=/data/study.sqlite3`. Сделайте это до загрузки PDF, чтобы материалы сохранялись после обновлений.
5. В **Settings → Networking** выберите **Generate Domain**. Проверьте страницу по HTTPS-адресу Railway. Путь `/health` возвращает состояние сервера.
6. В [@BotFather](https://t.me/BotFather) создайте бота и задайте для него **Menu Button** (команда `/setmenubutton`): название «Тесты» и HTTPS-адрес из шага 5. Откройте бота в Telegram и нажмите кнопку.

После изменения файлов в репозитории Railway развёртывает новую версию. Если вы поместили файлы в подпапку репозитория, задайте эту папку как **Root Directory** в настройках сервиса.

Если бот уже запущен на Railway, обновления в подключённой ветке GitHub развернутся автоматически. Чтобы повторно преобразовать исходные PDF, служат `import_moodle_pdf.py` и `import_digestive_pdf.py`; для запуска на Railway они не нужны.

## Локальный запуск

```bash
export ADMIN_TOKEN='придумайте-длинный-случайный-код'
export OPENAI_API_KEY='ваш-ключ-если-нужен-ии'
export PORT=8080
python3 server.py
```

Откройте `http://localhost:8080`. Без `OPENAI_API_KEY` поиск по точным вопросам и фрагментам PDF работает, а ответ ИИ отключён. Для публичного запуска разместите приложение на сервере с постоянным диском для `study.sqlite3` и HTTPS. Не публикуйте переменные среды и файл базы в открытом репозитории. Можно задать `DATABASE_PATH` для постоянного тома и `OPENAI_MODEL` для выбора модели.

## Материалы

Обычные пользователи не видят ссылку на загрузку. Администратор открывает **`https://ваш-домен/admin`**, вводит `ADMIN_TOKEN` и получает доступ к форме загрузки PDF. Код передаётся только при входе; сервер выдаёт защищённую сессию на 12 часов. Если `ADMIN_TOKEN` в Railway не задан, вход и загрузка недоступны. После работы нажмите «Выйти». Текстовые PDF индексируются для поиска. Для автоматического создания теста нужны вопросы с номером, варианты с буквами А–Г или A–D и строка `Ответ: Б` или `Правильный ответ: B`, например:

```text
1. Что изучает микроэкономика?
А) Поведение отдельных потребителей и фирм
Б) Только государственный бюджет
В) Климатические процессы
Ответ: А
```

PDF со сканами страниц требует предварительного распознавания текста (OCR). В материалах другого формата текст доступен для поиска, но вопросы для теста могут не извлечься. Ответ ИИ формируется по найденным фрагментам и может ошибаться; в интерфейсе он обозначен отдельно.

## Ограничения первой версии

- Прогресс текущего теста живёт в текущем сеансе, а ошибки сохраняются в localStorage Telegram WebView на этом устройстве, без учётных записей и синхронизации между устройствами.
- Для публичной нагрузки добавьте ограничение частоты запросов на уровне хостинга и резервное копирование SQLite.
- Поиск по базе опирается на совпадение слов; при отсутствии близкого вопроса используется ИИ или фрагмент PDF.
