# Учебная база — Telegram Mini App

Публичное мини-приложение для поиска ответов в PDF и прохождения тестов. Сервер использует Python 3.10+, SQLite и системную утилиту `pdftotext` (пакет poppler-utils). Сторонние Python-пакеты не требуются.

## С телефона: GitHub → Railway → Telegram

1. Создайте [частный репозиторий GitHub](https://github.com/new). Через **Add file → Upload files** загрузите содержимое папки `telegram-study-app` из архива **в корень репозитория**. Railway должен видеть `Dockerfile` в корне, поэтому загружать один ZIP-файл нельзя. Если кнопка загрузки скрыта, включите в браузере телефона режим «Версия для ПК».
2. На [Railway](https://railway.com/) создайте проект **Deploy from GitHub repo**, подключите репозиторий и дождитесь сборки Dockerfile. Приложение использует выданный платформой `PORT`.
3. В разделе **Variables** задайте `ADMIN_TOKEN` (длинный случайный код). Для ответов ИИ добавьте `OPENAI_API_KEY`; модель при необходимости задаётся через `OPENAI_MODEL`. Секреты храните в Railway, не в GitHub. Токен Telegram-бота этому приложению не нужен.
4. Подключите к сервису **Volume** с путём монтирования `/data` и установите `DATABASE_PATH=/data/study.sqlite3`. Сделайте это до загрузки PDF, чтобы материалы сохранялись после обновлений.
5. В **Settings → Networking** выберите **Generate Domain**. Проверьте страницу по HTTPS-адресу Railway. Путь `/health` возвращает состояние сервера.
6. В [@BotFather](https://t.me/BotFather) создайте бота и задайте для него **Menu Button** (команда `/setmenubutton`): название «Тесты» и HTTPS-адрес из шага 5. Откройте бота в Telegram и нажмите кнопку.

После изменения файлов в репозитории Railway развёртывает новую версию. Если вы поместили файлы в подпапку репозитория, задайте эту папку как **Root Directory** в настройках сервиса.

## Локальный запуск

```bash
export ADMIN_TOKEN='придумайте-длинный-случайный-код'
export OPENAI_API_KEY='ваш-ключ-если-нужен-ии'
export PORT=8080
python3 server.py
```

Откройте `http://localhost:8080`. Без `OPENAI_API_KEY` поиск по точным вопросам и фрагментам PDF работает, а ответ ИИ отключён. Для публичного запуска разместите приложение на сервере с постоянным диском для `study.sqlite3` и HTTPS. Не публикуйте переменные среды и файл базы в открытом репозитории. Можно задать `DATABASE_PATH` для постоянного тома и `OPENAI_MODEL` для выбора модели.

## Материалы

Нажмите «Загрузить материалы», введите `ADMIN_TOKEN`, предмет и PDF до 10 МБ. Текстовые PDF индексируются для поиска. Для автоматического создания теста нужны вопросы с номером, варианты с буквами А–Г или A–D и строка `Ответ: Б` или `Правильный ответ: B`, например:

```text
1. Что изучает микроэкономика?
А) Поведение отдельных потребителей и фирм
Б) Только государственный бюджет
В) Климатические процессы
Ответ: А
```

PDF со сканами страниц требует предварительного распознавания текста (OCR). В материалах другого формата текст доступен для поиска, но вопросы для теста могут не извлечься. Ответ ИИ формируется по найденным фрагментам и может ошибаться; в интерфейсе он обозначен отдельно.

## Ограничения первой версии

- Прогресс теста живёт в текущем сеансе, без учётных записей.
- Для публичной нагрузки добавьте ограничение частоты запросов на уровне хостинга и резервное копирование SQLite.
- Поиск по базе опирается на совпадение слов; при отсутствии близкого вопроса используется ИИ или фрагмент PDF.
